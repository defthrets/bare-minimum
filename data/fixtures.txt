; ============================================================================
; THINGS THIS MOD PUTS IN THE WORLD BECAUSE THE GAME DID NOT
; ============================================================================
;
; One per line:
;
;     model, x, y, z, heading     ; anything after a semicolon is a note
;
; The heading is the yaw in degrees, the way Menyoo's spooner reports it. Pitch
; and roll are not read: these are things standing on a floor, and a fridge on
; its side is not a fixture, it is a mess.
;
; MADE WHEN YOU ARE WITHIN A HUNDRED METRES and taken away again past a hundred
; and thirty, so the world is not carrying props nobody is looking at.
;
; NOTHING IS DOUBLED UP. If something of the same model is already standing
; within a metre and a half of the spot -- your own Menyoo copy of the same
; placement, or this mod's from before a script reload -- nothing is made. Two
; fridges inside each other is the classic way a mod that rebuilds a superseded
; spooner draft ruins a room.
;
; WHERE THE NUMBERS COME FROM. Stand the thing where you want it in Menyoo's
; spooner, save it, and open the xml: PositionRotation gives X, Y, Z and Yaw,
; and HashName gives the model. That is exactly where the line below came from.
;
; Turn the whole file off with [Fixtures] Enabled in BareMinimum.ini.
